# ORION AI STUDIO

> 团队所有项目的统一代码仓库

这里存放 ORION 团队的**全部项目**——它们是彼此独立、相互隔离的，只是放在同一个 GitHub 仓库里统一管理。

## 核心约定：一个仓库，多个隔离项目

与本仓库相处前，请先理解下面这一点：

- **这是一个 monorepo**：单个 GitHub 仓库里容纳多个团队项目。
- **每个项目完全独立**：拥有独立的目录、独立的依赖、独立的 README、独立的上线节奏，互不依赖、互不影响。
- **按项目隔离**：改动一个项目不会牵连其他项目；每个项目都有自己的工具链和构建方式。
- **目录即边界**：一个项目 = 仓库根下的一个顶层文件夹。文件夹内部就是该项目自己的代码库。

整体结构如下：

```
ORION-Projects/
├── README.md            # 本仓库说明（你正在看的就是它）
├── .gitignore           # 仓库级通用忽略规则
│
├── <project-a>/         # 一个项目 = 一个顶层文件夹（互相隔离）
│   ├── README.md        # 该项目的独立说明
│   ├── package.json     # 该项目的独立依赖（与其他项目无关）
│   ├── .gitignore       # 该项目的独立忽略规则（可选用）
│   └── src/ ...
│
└── <project-b>/         # 另一个项目，完全独立
    └── ...
```

## 想找某个项目

每个项目都自带独立 README。进入对应目录，直接阅读该目录下的 `README.md` 即可了解怎么跑起来、依赖什么、如何贡献。**请勿跨项目修改文件**——它们各自独立。

## 如何新增一个项目（懒得看这些乱七八糟的，直接丢给Agent让它看）

1. 在仓库根下新建一个顶层文件夹，以项目名命名（如 `project-name/`）。
2. 在文件夹内独立初始化工程：自己的 `package.json`、`README.md`、`.gitignore`、构建配置等。
3. 不依赖、不引用其他项目；不修改仓库根的公共文件（除非要改全局约定）。
4. 在下方「仓库包含的项目」表格中补一行登记表项。
