# 文字积累管理

> 文字积累管理工具：把散落的诗词、古文、名言、成语典故按标签积累下来，支持随句札记、图表统计与 AI 道场对话。

独立项目，不依赖 ORION-Projects 仓库内其他项目。

## 功能

- **鉴藏**：首页仪表盘，含每日金句、统计卡片、印章占比环形图、每日积累趋势图、来源排行条形图与词云
- **词句**：按标签分组的句子卡片；支持新增、随时修改（内容/出处/作者/标签）、标记收藏、删除；点击卡片可书写「随笔」札记
- **札记**：独立笔记管理与随句札记（本地 JSON 存储）
- **印鉴**：自定义内置 / 用户标签及配色（青瓷·竹韵低饱和色）
- **AI 道场**：浮动的 Markdown 渲染对话窗口（可拖动），可配置端点 / Key / 模型 / 系统提示词 / 温度，支持流式返回与一键总结为 Markdown 札记
- **雅舍**：数据存储目录设置（默认避开系统盘，减少 C 盘占用；使用 JSON 文件存储）

## 技术栈

- 后端：Python 标准库（`http.server` + `ThreadingHTTPServer`），零第三方运行依赖
- 前端：单文件 `index.html`（HTML / CSS / SVG / 原生 JS），新中式 UI，支持深浅主题切换
- 打包：PyInstaller 打成单文件 EXE
- 数据：本地 JSON（可指定目录）

## 快速开始

无需安装第三方依赖（仅需 Python 3）：

```bash
cd app
python server.py
```

服务启动后会自动打开浏览器访问 `http://127.0.0.1:8631/`（端口被占用会自动顺延）。关闭浏览器窗口后进程会自动退出，无后台残留。

## 打包为 EXE

```bash
python build_exe.py
```

产物为 `dist/文字积累.exe`，双击即可运行；图标来自 `assets/icon.ico`。

## 目录结构

```
文字积累管理/
├── README.md           # 本说明
├── build_exe.py        # 打包脚本
├── 文字积累.spec        # PyInstaller 配置
├── 文字积累管理.spec
└── app/
    ├── server.py       # HTTP 服务端 + 路由 + 心跳看门狗
    ├── store.py        # 数据模型（标签 / 词句 / 札记，JSON 持久化）
    ├── config.py       # 数据目录解析与记忆
    ├── bridge.py       # 辅助桥接
    ├── index.html      # 前端界面（单文件）
    ├── 文字积累整理.md   # 首次运行种子数据
    └── assets/         # 图标 / 背景等图片资源
```

## 数据存储

数据以 JSON 保存在用户指定目录（默认优先放在非系统盘，见 `config.py`）。`app_cfg.json` 为用户本地运行时配置，不入库。
