## 1. 简介

RTA-LLM 是一款基于**反思性主题分析法**（Reflective Thematic Analysis, RTA）的 AI 质性研究工具。它将质性研究的六阶段分析流程自动化，借助大语言模型（LLM）来辅助研究人员完成数据分析。

### 1.1 核心功能

- **全流程自动分析**: 一键执行 RTA 六阶段（数据熟悉 → 初始编码 → 主题构建 → 主题审视 → 主题定义 → 报告撰写）
- **单阶段分析**: 支持单独执行某个阶段，灵活控制分析过程
- **多模型支持**: OpenAI、Claude、Gemini、DeepSeek、Kimi、豆包、MiniMax 等
- **数据文件管理**: 上传、查看、删除研究数据文件
- **分析历史**: 自动保存所有分析记录，方便回溯和对比
- **本地运行**: 所有数据存储在本地，不上传到任何服务器

### 1.2 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11 (64位) |
| 内存 | 建议 8GB 以上 |
| 网络 | 需要联网（调用 LLM API） |
| Node.js | 无需安装（已内置） |

## 2. 安装与启动

### 2.1 安装

1. 双击 `RTA-LLM Setup 1.0.0.exe`
2. 选择安装目录（如 `D:\RTA-LLM`）
3. **勾选"创建桌面快捷方式"**（推荐）
4. 点击"安装"，等待完成

> 💡 建议不要安装在 C 盘，选择其他有足够空间的盘符。

### 2.2 启动

- **桌面快捷方式**: 双击桌面的 "RTA-LLM" 图标
- **开始菜单**: 开始菜单 → RTA-LLM
- **安装目录**: 运行 `RTA-LLM.exe`

### 2.3 启动过程

启动后您会看到加载界面，显示四步进度：

```
● 正在检查运行环境…
● 正在启动后端服务…（10-30秒，首次启动）
● 等待服务就绪…
● 正在加载应用…
```

加载完成自动进入主界面。**全程不超过 1 分钟。**

### 2.4 卸载

- **控制面板** → 程序和功能 → RTA-LLM → 卸载
- 或运行安装目录下的 `Uninstall RTA-LLM.exe`

## 4. 配置 LLM

### 4.1 进入设置

点击左侧导航栏的 **⚙ 设置**。

### 4.2 配置步骤

1. **选择模型提供商**

   | 提供商 | 说明 |
   |--------|------|
   | OpenAI | ChatGPT 系列 (gpt-4, gpt-4o, gpt-3.5-turbo 等) |
   | Claude | Anthropic Claude 系列 |
   | Gemini | Google Gemini 系列 |
   | DeepSeek | 深度求索 (deepseek-chat, deepseek-reasoner) |
   | Kimi | 月之暗面 Moonshot |
   | 豆包 | 字节跳动 Doubao |
   | MiniMax | MiniMax 系列 |
   | 自定义 | 兼容 OpenAI API 的自定义接口 |

2. **填写配置参数**

   | 参数 | 说明 | 示例 |
   |------|------|------|
   | API Key | 模型提供商的 API 密钥 | `sk-xxxxxxxx` |
   | API Endpoint | 自定义接口地址（可选） | `https://api.example.com/v1` |
   | Model | 模型名称 | `gpt-4o` / `deepseek-chat` |
   | Temperature | 温度参数 (0-2)，越高越有创造性 | `0.7` |
   | Max Tokens | 最大输出 token 数 | `4000` |
   | System Prompt | 系统提示词（可选） | 自定义分析指令 |

3. **测试连接**

   点击"测试连接"按钮，验证配置是否正确。

4. **保存配置**

   点击"保存"按钮。配置会自动保存到本地数据库。

### 4.3 API Key 获取

## 5. 执行分析

### 5.1 准备数据

RTA-LLM 支持以下方式输入数据：

- **直接输入**: 在分析页面的文本框粘贴研究数据
- **上传文件**: 支持 `.txt` 文本文件上传

### 5.2 全流程分析

一次性执行 RTA 全部六个阶段：

1. 进入 **分析** 页面
2. 输入或上传分析数据
3. 选择分析模式：**全流程分析**
4. 点击 **开始分析**
5. 系统自动依次执行六个阶段：

```
数据熟悉 → 初始编码 → 主题构建 → 主题审视 → 主题定义 → 报告撰写
```

6. 分析完成后查看完整报告

### 5.3 单阶段分析

只执行某个特定阶段：

1. 进入 **分析** 页面
2. 输入分析数据（文本或之前阶段的输出）
3. 选择分析模式：**单阶段分析**
4. 选择目标阶段：
   - **数据熟悉**: 通读数据，识别初步模式
   - **初始编码**: 系统性标注文本片段
   - **主题构建**: 将编码归纳为主题
   - **主题审视**: 检查主题的合理性和完整性
   - **主题定义**: 明确每个主题的内涵和边界
   - **报告撰写**: 生成正式分析报告

5. 点击 **开始分析**

### 5.4 分析进度

分析过程中可以看到：
- 当前执行阶段
- 进度百分比
- 实时输出内容

## 7. 常见问题

### 7.1 连接测试失败

**原因**: API Key 错误、网络不通、或 endpoint 配置错误。

**解决**:
1. 确认 API Key 正确（无多余空格）
2. 检查网络是否能访问 LLM 服务
3. 如果使用代理，确保系统代理配置正确

### 7.2 分析中途失败

**原因**: API 调用超时、Token 限制、或数据过长。

**解决**:
1. 适当调大 Max Tokens 参数
2. 将长数据分段分析
3. 查看错误提示信息，针对性调整

### 7.3 启动后窗口不显示

**原因**: 端口被占用或文件缺失。

**解决**:
1. 按 `Ctrl+Shift+Esc` 打开任务管理器，结束所有 RTA-LLM 进程
2. 重新启动应用
3. 如果仍不行，重新安装

### 7.4 如何更新配置

进入 **设置** 页面，直接修改参数后点击 **保存**。新配置会立即生效。

### 7.5 数据库位置

所有任务数据和配置存储在安装目录的 `data/rta.db` 文件中。备份该文件即可备份全部数据。

### 7.6 日志位置

运行日志保存在 `%APPDATA%\RTA-LLM\logs\`，排查问题时可以查看。

## 附录：RTA 方法简介

反思性主题分析法（Reflective Thematic Analysis）是一种质性研究方法，强调研究者对数据的主动反思和深度理解。六阶段流程：

1. **数据熟悉 (Familiarize)**: 深入阅读数据，记录初步印象
2. **初始编码 (Code)**: 系统性地为数据片段分配标签
3. **主题构建 (Themes)**: 将相关编码归纳为候选主题
4. **主题审视 (Review)**: 检查主题与编码和数据的一致性
5. **主题定义 (Define)**: 明确每个主题的本质和范围
6. **报告撰写 (Report)**: 整合分析结果，撰写研究报告

RTA-LLM 借助 LLM 的语义理解能力，自动执行这一流程，让研究者能够快速获得初步分析结果，并在此基础上进行人工深化和反思。
